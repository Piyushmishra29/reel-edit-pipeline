# Fia's Mahjong Collection — VO-driven product launch reel

A second example for `reel-edit-pipeline`, paired with the [Mother's Day Mahjong 2026](../mothers-day-mahjong/) event reel. This one is a **product launch reel** for the new Mahjong @ Fia's Lounge collection (tiles, mats, pushers, racks).

Final output: a **22.63s vertical reel** with on-screen captions, an animated website scroll over the CTA, and a soft music bed ducked under host voice-over.

| Spec | Value |
|---|---|
| Resolution | 1080 × 1920 (9:16) |
| Duration | 22.63s |
| Encoder | h264_videotoolbox (Mac) — no NVENC needed |
| Caption text | Burned-in via ImageMagick PNG overlay (works without `libfreetype`-enabled ffmpeg) |
| CTA visual | Animated scroll of `mahjongatfias.in` (long screenshot via Playwright + Chromium) |
| Audio mix | Host VO over a ducked music bed (sidechain compressor + loudnorm @ -16 LUFS) |

## How this differs from the BPM-driven example

The Mother's Day Mahjong reel was **BPM-driven**: librosa analysed the song, snapped every cut to a beat. Great for event reels.

This reel is **VO-driven**: the host narrates the caption script, and every visual cut lines up with her natural word breaks. No music BPM, no beat grid — `silencedetect` on her takes finds the speech ranges, and the SHOTS list locks each visual to a VO segment.

`scripts/build_reel.py` is the engine. It is intentionally a fresh script (not a fork of `pipeline/build_shotlist.py`) because the two timing models are different enough that sharing a base script would obscure both.

## Pipeline at a glance

```
01-source/ (MOVs) ─┐
                   ├──► silencedetect ─► VO ranges (per-clip src_in / src_out)
                   ├──► ffprobe       ─► inventory.csv
host clips ────────┘
02-thumbs/ ──────────► classification.csv (manual vision tagging per clip)
                                ↓
03-music/bed.wav (trimmed + faded) ──► render_reel.sh
03-music/assets/logo_mahjong_fias.png ─┤
03-music/assets/site_mahjongatfias.png ┤ (Playwright capture of CTA site)
04-edit/captions/*.png (one per line) ─┤
                                ↓
                       Pass 1: render each slot (1080×1920 silent MP4)
                       Pass 1b: extract each VO segment as WAV, concat
                       Pass 2: concat slots + mux VO + ducked music bed
                                ↓
                       05-renders/reel_v3.mp4
```

## End-to-end recipe (Mac VideoToolbox)

These are the exact steps used to produce v3. Adapt paths to your project.

### 1. Project layout

```
my-event/
├── 01-source/        # raw .MOV clips
├── 02-thumbs/        # generated thumbnails for vision tagging
├── 03-music/
│   ├── bed.wav                       # trimmed music bed (22.63s w/ fades)
│   └── assets/
│       ├── logo_mahjong_fias.png     # brand watermark for end card
│       └── site_mahjongatfias.png    # captured site for CTA scroll
├── 04-edit/
│   ├── captions/    # ImageMagick caption PNGs (generated by build_reel.py)
│   ├── tmp_slots/   # intermediate per-slot MP4s + VO WAVs (generated)
│   ├── shotlist.csv / shotlist.md     # generated
│   └── render_reel.sh                 # generated
└── 05-renders/
    └── reel_v3.mp4
```

### 2. Ingest + inventory

```bash
# Copy unique clips (skip duplicate "(1).MOV" files from AirDrop)
find /path/to/raw -maxdepth 1 -iname "*.mov" ! -iname "*\(1\)*" \
  -exec cp {} 01-source/ \;

# Build inventory.csv via ffprobe (filename, duration, width, height, codec, fps)
cd 01-source && {
  echo "filename,duration_sec,width,height,codec,fps"
  for f in *.MOV; do
    ffprobe -v error -select_streams v:0 \
      -show_entries stream=width,height,codec_name,r_frame_rate \
      -show_entries format=duration -of csv=p=0 "$f" \
    | awk -F, 'NR==1{w=$2;h=$3;c=$1;f=$4}NR==2{print FILENAME","$1","w","h","c","f}' \
      FILENAME="$f"
  done
} > inventory.csv
```

### 3. Thumbnails + manual vision tagging

```bash
# Midpoint thumbnails at 480px wide
for f in 01-source/*.MOV; do
  dur=$(ffprobe -v error -show_entries format=duration -of csv=p=0 "$f")
  mid=$(echo "$dur / 2" | bc -l)
  [ "${mid:0:1}" = "." ] && mid="0$mid"          # zsh: bc drops leading 0
  ffmpeg -y -v error -ss "$mid" -i "$f" -frames:v 1 \
    -vf "scale=480:-1" "02-thumbs/$(basename ${f%.MOV}).jpg"
done

# Build a labeled contact sheet for tagging
cd 02-thumbs && mkdir -p labeled
for f in IMG_*.jpg; do
  num="${f#IMG_}"; num="${num%.jpg}"
  magick "$f" -gravity south -background "#000000cc" -splice 0x32 \
    -fill white -font "/System/Library/Fonts/Supplemental/Arial Bold.ttf" \
    -pointsize 26 -annotate +0+4 "$num" "labeled/$f"
done
magick montage labeled/*.jpg -tile 5x7 -geometry 400x225+8+8 \
  -background "#1a1a1a" -font "/System/Library/Fonts/Supplemental/Arial Bold.ttf" \
  contact_sheet.jpg
```

Then write `02-thumbs/classification.csv` by hand (or via a multimodal LLM pass over the contact sheet). Columns: `filename,tag,confidence,note`. Tags used here: `host`, `racks`, `mats`, `tiles`, `setup`, `detail`.

### 4. Transcribe host clips + find speech boundaries

The pipeline needs to know exactly **where each VO sentence begins and ends** inside the host clips. Using `whisper-cpp` for transcription and ffmpeg's `silencedetect` for boundaries.

```bash
# Extract 16kHz mono WAVs from each host clip
for f in 01-source/IMG_3795.MOV 01-source/IMG_3797.MOV ...; do
  base=$(basename "$f" .MOV)
  ffmpeg -y -v error -i "$f" -vn -ar 16000 -ac 1 -c:a pcm_s16le \
    "host_audio/${base}.wav"
done

# Transcribe each to know which line is in which clip
MODEL=/path/to/whisper.cpp/ggml-medium.en.bin
for f in host_audio/*.wav; do
  whisper-cli -m "$MODEL" -f "$f" -nt -np
done

# CRITICAL: use a generous silencedetect threshold (-45dB, 0.25s).
# A tighter threshold (-30dB) silently chops trailing word releases and
# whole quiet phrases. We learned this the hard way in v1.
for f in host_audio/*.wav; do
  echo "=== $f ==="
  ffmpeg -hide_banner -nostats -i "$f" \
    -af "silencedetect=noise=-45dB:duration=0.25" -f null - 2>&1 \
    | grep "silence_"
done
```

Hand-pick the cleanest contiguous take of each sentence from the silence map; record it in the `VO` list inside `scripts/build_reel.py` as `(file, src_in, src_out, line_label, line_text)`.

### 5. Capture the CTA site (only if you have a website-scroll slot)

```bash
npm install --no-save playwright
npx playwright install chromium

# Force IPv4 if your network rejects v6 routes to YouTube/Chromium API
node scripts/capture_site.js   # writes 03-music/assets/site_<host>.png
```

`capture_site.js` opens the URL in a 540×960 viewport at 2× DPR to get a clean mobile-shaped 1080-wide long screenshot. The resulting PNG is taller than 1920 — that's what gives the scroll its travel distance.

### 6. Get the music bed (subtle background under VO)

```bash
# yt-dlp + force IPv4 because the YouTube search API often refuses IPv6
yt-dlp -4 --no-playlist -x --audio-format wav --audio-quality 0 \
  -o "03-music/bed_source.%(ext)s" \
  "ytsearch1:<artist> <track>"

# Trim to exact reel duration + fade in/out so the cut isn't audible
ffmpeg -y -v error -ss 0 -t 22.63 -i 03-music/bed_source.wav \
  -af "afade=t=in:d=0.8,afade=t=out:st=21.13:d=1.5" \
  03-music/bed.wav
```

Music **does not need to match BPM** — VO drives timing, music is just a soft bed. The sidechain compressor in `render_reel.sh` ducks the music when the host speaks. The bed plays at `volume=0.18` by default; lower it if music still competes with VO.

### 7. Edit `VO`, `CUTS`, `CAPTIONS` in `scripts/build_reel.py`

```python
VO = [
    ("IMG_3795.MOV", 5.97, 9.23,  "hook",     "..."),
    ...
]

CUTS = [
    # (vo_index, sub_offset, sub_dur, role, file, src_in, label)
    (0, 0.00, 3.26, "hook",   "IMG_3795.MOV", 5.97, "Host hero"),
    ...
    # Special sentinels:
    (4, 0.00, 3.53, "cta",    "WEBSITE_SCROLL", 0.0, "..."),
    (None, 0.00, 1.50, "end", "LOGO_END_CARD",  0.0, "Brand card"),
]

CAPTIONS = {
    "hook":    "THE MOST BEAUTIFUL\nMAHJONG SETUP IS HERE",
    "reveal":  "A NEW COLLECTION\nAT FIA'S LOUNGE",
    ...
    "end":     None,    # no caption on end card
}
```

Then run:

```bash
python3 scripts/build_reel.py
bash 04-edit/render_reel.sh
```

The script will:

- Sanity-check every visual slot against `01-source/inventory.csv` — refuses to render if a slot needs more frames than the source clip has. (v1 silently chopped a 2.42s slot down to 1.43s because the source was too short; this assert prevents that recurring.)
- Generate one caption PNG per unique role in `04-edit/captions/`
- Render each slot with caption overlaid (and either the host clip, the LOGO end card, or the WEBSITE_SCROLL animation)
- Extract + concat each VO segment into a single audio bed
- Mux VO + music with sidechain ducking, loudnorm to -16 LUFS (Instagram spec)

## Known gotchas

- **`ffmpeg` without libfreetype** (e.g. plain `brew install ffmpeg`) cannot use `drawtext`. We render captions as transparent PNGs via ImageMagick and overlay them. If your build does have libfreetype, you can simplify by switching back to `drawtext`.
- **yt-dlp over IPv6** routinely fails YouTube search with `No route to host`. Always pass `-4`.
- **`-frames:v N` truncates silently** when N exceeds available source frames. The sanity check in `build_reel.py` catches this; never remove it.
- **`silencedetect -30dB`** is too aggressive for soft-spoken takes. Use `-45dB / 0.25s` and let the editor manually pick the cleanest continuous span.
- **`-c:v copy` in Pass 2** carries video unchanged from concat. If captions need to be applied across the whole reel post-concat instead of per-slot, switch to a re-encode in Pass 2.
